# Stock Portfolio Tracker
A Simple Python program that calculates the total value of  a stock portfolio.

Users can enter stock names and quantities, and the program calculates the investment value using 
predefined stock prices.

## How to Run 
1. Make sure Python  is installed.
2. Run the following command:

  'python stock_portfolio_tracker.py'
3. Enter the stock names ans quantities when prompted.
4. View the total investment value.
